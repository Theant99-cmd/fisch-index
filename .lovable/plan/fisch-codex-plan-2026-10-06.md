# Fisch Codex — Plan

An offline-capable Fisch companion app with six tabs, built on data pulled from fischipedia.org. Missing values show "?", and every entry links to its wiki source page.

## Data (from Fischipedia)

- I'll pull rods, fish, enchants, relics, totems/items and hunts from the fischipedia.org pages (and their infobox data) while building, then bake them into the app. That way it works offline and never makes live requests.
- Each record keeps its `sourceUrl`. Missing fields are stored as empty and shown as "?". Nothing gets guessed.
- If a page can't be read or a field is unclear, it stays "?". Nothing is filled in by hand from memory.
- Rods that can no longer be obtained, according to the wiki, get the [limited] tag.
- The 6 custom stages (Starter, Early Utility, Mid Game, Late Game, Endgame, Completion) plus Special are assigned by a written rule based on price, stats, passives and how the rod is obtained. The official wiki stage number is shown next to it. Each rod's stage is my own call, made by that rule, and labeled as such.

## Tabs

1. **Rods**: card/table view with search, sort by any stat, stage filter, an Owned checkbox, and a compare tray for up to 3 rods shown side by side. Stage-colored accents.
2. **Fish**: searchable list with filters (rarity, region, weather, time). Fields: bait, weight range, value, Progress Speed modifier, counter-stat advice. Counter-stat advice comes only from the wiki's own text, otherwise "?".
  - **Catch log**: add catches with variant and weight, track personal best per fish, and export/import as JSON.
3. **Enchants & Relics**: pick a rod and an enchant (relics are included in the list) to see base stats, the change, and the result side by side. Effects that aren't numbers are shown as text.
4. **Items**: totems and other items, with effect, price, how obtained and source.
5. **Hunts**: quick cards for the major server hunts: trigger, location, duration, notable fish, and wiki link.
6. **Milestones**: live progress bars.
  - Destiny Rod: Bestiary fish caught, out of 350.
  - Masterline Rod: Bestiary complete (excluding Secret, Apex, Divine Secret and Limited fish) plus Rod Journal complete (excluding Brick, Dave, Shady and Moonlit Rods). [limited] rods are also left out of totals.

## Style

Dark navy theme, a distinct accent color per stage, monospace numbers, and a compact, information-dense layout.

## Saving progress

Owned rods, the catch log and settings are saved in the browser. Every read and write is wrapped in try/catch so a blocked or corrupt save never breaks the app.

## Offline / single file

The app runs here as normal. I'll also produce a self-contained `fisch-codex.html` download that has all data inlined and works offline.

## Technical details

- `src/data/*.json` is generated by a one-off scraping script (wiki pages, parsed infoboxes) stored in the project so data can be refreshed later.
- Routes: `/` (Rods), `/fish`, `/enchants`, `/items`, `/hunts`, `/milestones`, each with its own head metadata.
- `src/lib/storage.ts` is a safe localStorage wrapper. `src/lib/stages.ts` holds the stage rule. `src/lib/milestones.ts` holds the progress math, with unit tests for the 350 threshold and the exclusion lists.
- The single HTML file is made with a separate inline build and saved to Files.
- Caveat: Fischipedia's coverage decides how complete the data is. Gaps will show as "?" rather than being filled in.
